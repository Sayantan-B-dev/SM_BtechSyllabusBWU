 Q1. Explain the key features of Python programming language.

 Ans.
  1. Simple and readable : English-like syntax.
  2. Interpreted : runs line by line, no compilation
     needed.
  3. Dynamically typed : no need to declare int,
     float, etc. Example: x = 10.
  4. High level + portable : same code runs on
     Windows / Linux / Mobile (with interpreter).
  5. Large library : math, string, random, etc.
  6. Object oriented + functional support.
  7. Free and open source.
  8. Used in AI, web, automation, data science.


 Q2. Discuss different data types in Python with uses.

 Ans.
  1. int    : whole numbers. Ex: x = 10. Use: count,
     factorial, age.
  2. float  : decimal numbers. Ex: p = 10.5.
     Use: average, percentage.
  3. str    : text in quotes. Ex: s = "hello".
     Use: name, sentence processing.
  4. bool   : True / False. Use: conditions, flags.
  5. list   : ordered, changeable [1,2,3]. Use: marks,
     items list.
  6. tuple  : ordered, unchangeable (1,2,3). Use:
     fixed data like (day, month, year).
  7. dict   : key:value pairs {"a":1}. Use: student
     record, phone book.
  8. set    : unique items {1,2,3}. Use: remove
     duplicates.

 CODE:
 --------------------
  x = 10          # int
  y = 10.5        # float
  s = "hello"     # str
  l = [1, 2, 3]   # list
  t = (1, 2, 3)   # tuple
  d = {"a": 1}    # dict
 --------------------


 Q3. Explain the structure of if, elif, else with
     functionality.

 Ans.
  Used for decision making.

  Syntax:

  CODE:
  --------------------
  if condition1:
      statement-1
  elif condition2:
      statement-2
  else:
      statement-3
  --------------------

  Working:
  1. if : checked first. If True, its block runs.
  2. elif : checked only if previous if/elif is
     False. Any number of elif allowed.
  3. else : runs when all above are False. Optional.

  Example:

  CODE:
  --------------------
  marks = 75
  if marks >= 90:
      print("A")
  elif marks >= 60:
      print("B")
  else:
      print("C")
  --------------------
  OUTPUT:
  --------------------
  B
  --------------------


 Q4. Explain the use of break and continue in loops.

 Ans.
  break    : stops the loop fully and comes out.
  continue : skips current round and goes to next
             round. Loop does NOT stop.

 CODE:
 --------------------
  for i in range(1, 6):
      if i == 3:
          break
      print(i)
  # Output: 1 2  (loop stops at 3)

  for i in range(1, 6):
      if i == 3:
          continue
      print(i)
  # Output: 1 2 4 5  (3 is skipped)
 --------------------

 Q5. Write a Python program and explain its working
     procedure.

 Ans.
  Steps in a Python program:
  1. Write source code in .py file.
  2. Interpreter reads line by line.
  3. Converts to bytecode (.pyc).
  4. PVM (Python Virtual Machine) converts bytecode
     to machine code and executes.
  5. Output is shown.

 CODE:
 --------------------
  # add.py
  a = 10
  b = 20
  c = a + b
  print("Sum =", c)
 --------------------
 OUTPUT:
 --------------------
  Sum = 30
 --------------------
  Explanation: a,b store 10,20. c stores sum.
  print() displays result.

 Q9. Uses of break, continue, pass + loop control.

 Ans.
  break    : exit loop. Ex: stop search when item
             found.
  continue : skip one iteration. Ex: skip absent
             student.
  pass     : do nothing placeholder. Needed where
             Python expects a block but you want to
             write code later.

 CODE:
 --------------------
  for i in range(5):
      if i == 2:
          pass      # do nothing, go ahead
      print(i)
 --------------------

  Diagram (loop control):

  --------------------
   start loop
      |
   condition?
    /    \
  True   False -> exit
   |
  break? -> Yes -> exit loop
   |
  continue? -> Yes -> next round
   |
  normal body -> next round
  --------------------


 Q10. What is source code, byte code, machine code?
      How connected?

 Ans.
  1. Source code (.py) : human readable code you
     write. Ex: print("hi").
  2. Byte code (.pyc) : intermediate code made by
     interpreter (in __pycache__). Not readable,
     but portable.
  3. Machine code (0/1) : CPU readable binary.
     Actually executed.

  Connection (ASCII diagram):

  --------------------
   Source (.py)
       |
       v  [compile]
   Bytecode (.pyc)
       |
       v  [PVM interprets]
   Machine code (0/1)
       |
       v
   CPU executes -> Output
  --------------------

 Q20. Difference between slicing and indexing.

 Ans.
  Indexing : gets ONE character. Ex: s="hello",
             s[0]="h", s[-1]="o".
  Slicing  : gets a PART (substring). Syntax
             s[start:stop:step]. Ex: s[1:4]="ell",
             s[::-1] reverses.

  Diagram:

  --------------------
   s =  h  e  l  l  o
   idx  0  1  2  3  4
   s[1] = e      (indexing, 1 char)
   s[1:4] = ell  (slicing, many chars)
  --------------------

 Q32. Python data structures: list vs tuple vs dict.

 Ans.

          key-value, keys unique.

 Q56. Reverse using function.

      r = 0
      while n > 0:
          r = r*10 + n%10
          n //= 10
      return r

  print(reverse_num(123))  # 321
