Btech Syllabus
==============

This repository contains B.Tech course materials organized by semester and subject. It includes notes, tutorials, modules, assignments, and projects for each course.

Subject Layout
--------------

Each theory subject follows this structure:

```
_Subject Name/
├── Module-01/
├── Module-02/
├── Module-03/
├── Module-04/
├── Module-05/
├── Tutorials/
└── README.md
```

Lab subjects include lab-specific materials alongside modules and tutorials.

Getting Started
---------------

1. Clone the repository:

   git clone <repository-url>

2. Navigate to the desired semester:

   cd 3rdSem

3. Open a subject folder to view modules and tutorials.
